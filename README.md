# Food Ordering Application

A responsive food ordering web application built with React.js that allows users to browse meals, manage cart items, and place orders through an interactive checkout flow.

## Features

- Browse available meals dynamically
- Add and remove items from the cart
- Real-time cart state updates
- Checkout and order submission flow
- Form validation for user inputs
- Modal handling using React Portals
- Responsive user interface
- Reusable component architecture

## Tech Stack

- React.js
- JavaScript (ES6+)
- Context API
- React Hooks
- CSS
- REST API

## Concepts Practiced

- State Management with Context API
- Component Reusability
- React Portals
- Form Handling & Validation
- HTTP Requests
- Conditional Rendering
- Dynamic UI Updates
